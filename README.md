# Joshis12 — GitHub Pages

Public-facing static preview for Joshis12. The food catalog uses example data, and `docs/login.html` is a visual login preview only; it is not connected to authentication. Do not enter real credentials on the GitHub Pages site.

GitHub Pages serves the files in `docs/`. The PHP application, authentication backend, reservations, and database are not included in this deployment. The ignore rules intentionally keep the PHP application and database dump out of this public repository.
